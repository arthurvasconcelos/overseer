# Concepts


Key ideas behind how overseer is structured and how it handles configuration.

- [Brain](/concepts/brain) — Your private config repo — the single source of truth for your personal setup.
- [Config](/concepts/config) — Two-layer merge, all config keys, and the JSON Schema.
- [Secrets](/concepts/secrets) — 1Password `op://` references resolved at runtime.
- [WSL](/concepts/wsl) — Running under WSL with 1Password on the Windows side: `op.exe`, `ssh.exe`, and the WSL commit signer.
